---
name: maintain-changelog
description: Use this skill when making changes to code to ensure that all modifications are documented in the changelog.
---
- Open the CHANGELOG.md file in your project.
- Under the '## Unreleased' section, add a bullet point for each change made.
- Format each bullet point as follows: `- fix(<function name>): <short description of the change>`.
- Ensure that you include at least three bullet points for significant changes or bug fixes.
- Review previous entries for consistency in formatting and style.
- If applicable, categorize changes (e.g., features, fixes, documentation).
- Update the version number in the changelog when preparing for a release.
- Regularly review the changelog to ensure it reflects the current state of the project.
