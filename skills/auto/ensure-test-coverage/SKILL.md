---
name: ensure-test-coverage
description: Use this skill when making changes to code to ensure that adequate tests are created or updated.
---
- Identify all functions that have been modified or added.
- For each function, determine the expected behavior and edge cases.
- Write unit tests for each function, ensuring that:
  - All branches of logic are tested.
  - Edge cases are included (e.g., empty inputs, invalid data).
- Create a separate test function for each bug fix or feature addition.
- Organize tests in a dedicated test file or module.
- Run the test suite after writing tests to ensure they pass.
- Use a coverage tool to check that all code paths are tested.
- Document the purpose of each test in comments.
